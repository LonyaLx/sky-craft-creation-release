## 四、魔改与平衡建议

### 4.1 戴森球系统融入（高优先级）
Dyson Cube Project 是 v1.1.1 新增的大亮点，但目前可能没有很好地融入整合包进度。

**建议：**
```
前期：太阳能板（Powah）→ 中期：极端反应堆 → 后期：龙研能量核心
                                                           ↓
                                              终极：戴森球（需要大量资源建造）
```

- 戴森球作为**终极发电目标**，需要投入大量 ATM 矿/无尽材料
- 建造过程分阶段：卫星 → 轨道镜 → 完整戴森球
- 产出极高但建造成本也极高，作为"毕业前最后一个大项目"
- 加入任务线引导玩家建造戴森球

### 4.2 Iron Furnaces 定位（中优先级）
新增了 Iron Furnaces，但和 Mekanism 富集炉、IF 速熔炉、EIO 烧结炉功能重叠。

**建议：**
- Iron Furnaces 定位为**前期→中期过渡**的熔炉升级
- 铁熔炉 → 金熔炉 → 钻石熔炉 → 下界合金熔炉
- 每级速度更快、燃料效率更高，但只能烧原版物品
- 模组专属物品的冶炼还是走各自模组的机器
- 这样 Iron Furnaces 有明确的定位，不会和其他模组冲突

### 4.3 ATM 三矿空岛化（高优先级）
AllTheModium 新增了三种终局矿，但空岛环境下获取方式需要确认。

**建议：**
- **Allthemodium**：下界获取 → 筛下界岩有极低概率掉落 + 神秘农业种子
- **Vibranium**：主世界深板岩 → 筛砂砾/深板岩有极低概率 + 神秘农业种子
- **Unobtainium**：末地获取 → 筛末地石有极低概率 + 神秘农业种子
- 三矿都加入 Ex Machinis 通量筛掉落（极低概率）
- ATM 装备工具作为介于龙研和无尽之间的过渡
- 加入任务线引导获取和使用 ATM 三矿

### 4.4 能源系统再平衡（中优先级）
新增戴森球后，能源体系需要重新梳理：

| 阶段 | 发电方式 | 大致产能 |
|:---|:---|:---|
| 前期 | 太阳能板/地热/气动 | < 1k FE/t |
| 中期 | 极端反应堆 / 聚变 / 龙研 | 1k ~ 50k FE/t |
| 后期 | 龙研能量核心 / ATM 发电 | 50k ~ 500k FE/t |
| 终极 | 戴森球 | 500k FE/t+ |

**需要检查/调整：**
- ExtremeReactors 燃料消耗倍率（当前 1.2x，是否合理？）
- Powah 太阳能产出（已削弱，是否还需要调整？）
- 戴森球建造成本和产出比例

### 4.5 Almost Unified 矿物统一检查（低优先级）
Almost Unified 已经加了，但需要检查：
- 所有模组的矿石/锭/粉是否都统一了
- 有没有遗漏的模组矿物
- IE 插件是否正常工作
- 统一后的矿物名称是否汉化正确

### 4.6 存储系统再梳理（中优先级）
存储模组太多了，需要明确梯度：

```
前期：木桶/箱子 → 中期：FunctionalStorage/Sophisticated → 后期：AE2
                                                                 ↓
                                              扩展：MegaCells / AdvancedAE / ExtendedAE
```

**建议：**
- 各模组的存储组件配方需要逐级依赖，不能跳级
- 最大容量（创造级）统一走终局合成路线
- 检查是否有某个模组的存储过于 OP，可以跳过其他模组

## 六、创意玩法建议

### 6.1 戴森球工程线 ⭐⭐⭐
把 Dyson Cube Project 做成一个**大型工程线**：
```
阶段1：发射首颗卫星（需要火箭/发射平台）
阶段2：建造轨道镜阵列（反射阳光到地面接收站）
阶段3：建造太阳能卫星（SPS）
阶段4：完整戴森云（Dyson Swarm）
阶段5：戴森球（Dyson Sphere）终极形态
```
每个阶段需要投入大量资源，产出也逐级提升。做成类似"工业革命"的感觉。

### 6.2 自然灵气仪式合成线 ⭐⭐
用 Nature's Aura 的**森林仪式**（Ritual of the Forest）做一些高级物品的**替代合成路线**：
- 灌注铁锭 → 某些高级合金的替代来源
- 灵气转化 → 某些稀有资源的缓慢获取
- 自然祭坛 → 附魔/强化装备的另一种方式

不强制，但提供一条"魔法向"的替代路线，增加玩法多样性。

### 6.3 集成动力学自动化挑战 ⭐⭐
设计几个"用集成动力学实现 XXX"的挑战任务：
- 用 ID 自动控制筛矿系统
- 用 ID 做 AE2 网络的高级控制
- 用 ID 实现自动合成调度

给喜欢折腾自动化的玩家一个深度玩法。

### 6.4 ATM 三矿"寻宝"系统 ⭐
利用 AllTheModium 三矿设计一个"寻宝"系统：
- 不同维度/环境有不同的 ATM 矿
- 需要特定工具/等级才能开采
- 三矿可以合成更强的装备工具
- 最终可以做"ATM 套装"作为龙研到无尽之间的过渡

### 6.5 模块化路由器物流挑战 ⭐
设计一个"只用模块化路由器实现全自动化基地"的挑战任务线。

### 6.6 终极工厂设计大赛 ⭐
设计一个终极目标：建造一个每秒产出 X 个终极锭的自动化工厂。
- 需要用到多模组联动
- 可以用不同的方案实现
- 鼓励玩家发挥创造力

## 八、风险与注意事项

1. **模组兼容性**：新增模组前务必检查与 NeoForge 版本和其他模组的兼容性
2. **性能影响**：232 模组已经不少了，再加模组要注意性能，尤其是大型内容模组
3. **任务量**：857 任务已经很多了，新增内容要控制任务数量，避免玩家疲劳
4. **平衡难度**：新增内容要注意和现有难度曲线衔接，避免突然变难或变简单
5. **空岛适配**：所有新增内容都要考虑空岛环境下的获取途径，不能有"只能挖矿获取"的东西
6. **汉化完整性**：新增模组需要补汉化，v1.1.1 已经做到 0 缺口，保持这个标准

---

## 九、总结

v1.1.1 已经是一个相当完善的整合包了，232 模组 + 857 任务，内容量很足。主要的改进方向是：

1. **瘦身**：删掉功能重复的小模组，保持精简
2. **融入**：把新增的戴森球、ATM 三矿、Iron Furnaces 更好地融入现有进度
3. **补全**：弱模组增加存在感，前期优化体验
4. **亮点**：戴森球是最大的亮点，值得重点打造

你觉得哪些方向比较感兴趣？我们可以挑几个重点深入设计。
